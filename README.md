# MY MUNAY — Kiosco & Avícola

Tienda online simple para kiosco/avícola con panel de administración.

- Frontend: HTML/CSS/JS puro (un solo archivo `index.html`).
- Datos: Firebase **Realtime Database** (proyecto `raki-64e1c`).
  - `products` — catálogo (add/update/delete con transacciones de stock).
  - `orders` — historial de pedidos (descuentan stock automáticamente).
  - `settings/storeInfo` — nombre y logo de la tienda.
  - `settings/heroCarousel` — imágenes del carrusel.
- Carrito y pedidos: localStorage + envío por WhatsApp al dueño (`wa.me`).
- Admin: contraseña `VALENTINA`, panel con gestión de productos/orders/carrusel/config.
